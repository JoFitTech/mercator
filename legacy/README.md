# Legacy-Bereich

Dieser Ordner enthält Bestandteile der früheren, breiter angelegten Produktstruktur.

## Warum verschoben?
Die ursprüngliche Struktur war stark auf eine umfassende Produktplattform (React + PocketBase + diverse Produktfeatures) ausgelegt und passt nicht zum reduzierten Uni-Scope von **Mercator**.

## Enthaltene Altbestände
- `previous_product_stack/apps/`: ehemalige Web- und PocketBase-Anwendung
- `previous_product_stack/package*.json`, `.nvmrc`, `.version`: zugehörige JS/Node-Projektdateien

## Hinweis
Die Inhalte wurden bewusst **nicht gelöscht**, sondern geordnet ausgelagert, damit sie bei Bedarf nachvollziehbar bleiben.
